# Venue Wrangler Enterprise prototype

This is a Phase 5 interactive Flutter prototype. It demonstrates the role-aware Today and Event Command experiences, scheduling coverage, service fulfillment, stock reconciliation, responsive navigation, and pending-sync feedback using representative data.

## Run

Install a current Flutter SDK, then run:

```powershell
flutter pub get
flutter run -d chrome
```

The prototype intentionally uses local representative state. It does not connect to production systems or represent Phase 6 authorization, offline storage, or API implementation.
